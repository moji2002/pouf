# pouf

**Pouf is not installed from npm.** It is a [shadcn-style](https://ui.shadcn.com) registry — you copy the component source into your own project and own it.

```bash
npx shadcn@latest add https://pouf.dev/r/button.json
```

Docs and every component, live: **[pouf.dev](https://pouf.dev)**.

This npm package exists only to reserve the name and point here.
