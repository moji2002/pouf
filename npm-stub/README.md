[1st-Pouf](https://1st-pouf.worksonmy.dev) is a [shadcn-style](https://ui.shadcn.com) registry. Add components from the registry so their source is copied into your project and remains yours.

```bash
npx shadcn@latest add https://1st-pouf.worksonmy.dev/r/button.json
```
