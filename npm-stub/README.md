# pouf-ui

**1st-Pouf is not installed from npm.** It is a [shadcn-style](https://ui.shadcn.com) registry — you copy the component source into your own project and own it.

```bash
npx shadcn@latest add https://1st-pouf.worksonmy.dev/r/button.json
```

Docs and every component, live: **[1st-pouf.worksonmy.dev](https://1st-pouf.worksonmy.dev)**.

This npm package exists only to reserve the name and point here.
